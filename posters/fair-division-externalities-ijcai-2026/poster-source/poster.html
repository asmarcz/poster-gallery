5MULTICOLOR DISCREPANCY
what it is
color a ground set of m elements with q colors: χ:[m]→[q]. a single coloring is judged by every weight vector w∈[0,1]m: each pair of color classes must carry almost equal weight. wdiscq,∞​ is the best achievable worst-case gap.
the dictionary
additive fair division — no externalitiesdiscrepancy
agents⇄colors
items⇄elements
valuations⇄weight vectors
allocation⇄q-coloring
swap-envy of a pair⇄imbalance of a color pair
with externalities this direct map breaks — Prop. 1 restores it: each ordered pair’s asymmetric envy values vij​ become the weight vectors:
THE BRIDGE · PROP. 1 Vi​(Ai↔j)−Vi​(A)=vij​(Aj​)−vij​(Ai​) swap-envy with externalities ⇄ pairwise bundle envy — bounds transfer both ways
